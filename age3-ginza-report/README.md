# Age.3 銀座店 売上報告

銀座店の毎日の売上報告を、スマホだけで入力してLINEに送るアプリ。
嘉麻店のアプリ（`age3-kama-report`）とは別のアプリで、データもPINも別々に持つ。

## 何のためのアプリか

これまでLINEに手打ちしていた報告を、そのままの体裁で出せるようにしたもの。
**受け取る側の読み方は変わらない**（全角の￥、項目名のあと半角スペース2つまで同じ）。

```
9/12(土)
総売上  ￥579,300
現金  ￥133,300
PayPay  ￥40,850
CR  ￥405,150

客数  336組
客単価  ￥1,724

口コミ  0件
総口コミ  17,034件

Uber  4件
```

手打ちと違うのは次の3つ。

- **客単価は自動**。総売上 ÷ 客数 なので、電卓を叩かない。
- **内訳が合うか確かめる**。現金＋PayPay＋CR が総売上と違えば、送る前に赤で出る。
- **残る**。送ったあとも履歴と分析に残るので、先月と比べられる。

**金庫の10万円チェック**も同じ画面に入れてある。トークでは別のメッセージで
送っていたが、同じ夜の締め作業なので1通にまとめられる。

## 経費

立て替え払いもトークに毎日流れているので、同じように出せるようにした。
こちらも体裁はそのまま。

```
9/13(日)
使用者:野口
店名:セブンイレブン
金額:¥7,009
```

- **使用者と店名はボタンで選ぶ**。トークでは「セブン」と「セブンイレブン」、
  「京プロ」と「京橋プロデュース」が混ざっていた。選べば書き方がそろう。
  一覧に無ければその場で打てる。
- **送ったあとも使用者は選んだまま**。続けて2件目を入れられる。
- **立て替えた人ごとの月合計**が出る。精算のときにそのまま使える。

レシートの写真は今までどおり別に送る（アプリは写真を扱わない）。

在庫チェックは入っていない（銀座店では別の表で回しているため）。

## 画面

| 画面 | 何をするか | PIN |
| --- | --- | --- |
| 売上 | その日の数字を入れて、LINEに送る | 入店 |
| 経費 | 立て替え払いを1件ずつ送る。日ごと・月ごとの合計 | 入店 |
| 履歴 | 過去の売上報告。前の日と比べた増減つき | 入店 |
| 分析 | 平均・決済手段の割合・曜日ごとの売上・推移 | 管理 |
| 設定 | 名前の一覧、PINの確認、データの削除 | 管理 |

経費を1件消すのは入店PINでできる（打ち間違いを自分で直せるように）。
**全部消すのは管理PIN**。

## PIN

`lib/auth.ts` の2行だけで決まる。変えるときはここを書き換えてデプロイする。

- 入店PIN `1959` … アプリ全体（90日おぼえる）
- 管理PIN `3030` … 分析と設定（1日でおぼえ直し）

## 保存先

`POSTGRES_URL` があればサーバー（Vercel Postgres）に、無ければブラウザの
localStorage に保存する。売上報告（`reports`）と経費（`expenses`）は別の表に持つ。
経費は1日に何件も、買った人がその場で出すので、夕方にまとめて入れる売上報告と
同じ入れ物にすると片方の保存でもう片方を消してしまうため。**DBを繋がなくても動く**ので、先に使い始めて後から繋げる。
今どちらで保存しているかは設定画面の「保存先」に出る。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Vercel では **Root Directory を `age3-ginza-report`** にして、嘉麻店とは別の
プロジェクトとしてデプロイする。
