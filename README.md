# Age.3 店舗チェック

銀座・原宿・浅草の店舗チェックリスト（全店共通版）のウェブアプリ。
出張中にスマホ縦持ち・片手で回れるように作ってある。元のエクセル
「Age3 店舗チェックリスト.xlsx」の 75項目・12カテゴリ・加重スコア・是正管理を
そのまま移植し、現地での入力と報告までを1つにまとめたもの。

## できること

- **店舗切替 1タップ** — 銀座／原宿／浅草。店舗ごとに「共通66項目＋店舗別追加」を出し分ける
  （銀座70／原宿70／浅草67項目）
- **12カテゴリのアコーディオン** — 上部に進捗（例 34/75）と加重スコアを常時固定表示
- **判定は4択の大ボタン** — ○＝1.0／△＝0.5／×＝0／対象外＝集計から除外。
  色だけでなく記号（✓ ／ ！ ／ ✕ ／ —）でも区別する
- **加重スコア** — Σ(重み×判定係数) ÷ Σ(重み)。S=5／A=3／B=1。
  80%以上＝緑／60〜79%＝黄／60%未満＝赤。**S項目に×が1件でもあれば総合何%でも赤**
- **×をつけたら担当・期限が開く** — 未記入なら警告を出す
- **メモ＋写真添付** — 写真は端末内だけに保存（長辺1280pxのJPEGに自動縮小）
- **要改善リスト** — ×と△だけを抽出。その場で店長に見せる／コピーする／印刷する
- **前回との比較** — 各項目に前回の判定と「是正済み／改善／悪化」を表示
- **是正管理台帳** — 全店・全視察を横断して×を追跡（対応中／期限切れ／完了）
- **履歴・店舗比較** — 3店を同じ基準で並べ、「原宿だけの問題」か「全社の問題」かを見る
- **書き出し** — LINEに貼れるプレーンテキスト／CSV（視察・是正台帳・履歴）／JSONバックアップ
- **オフライン動作** — PWA。ホーム画面に追加すれば電波が弱くても開ける

## 使い方（現地）

1. ホームで店舗を選び「チェックを始める」
2. カテゴリを開いて上から判定していく。×は担当・期限をその場で埋める
3. 「要改善」タブで×と△だけを店長に見せる
4. 「結果」タブで加重スコアを確認し、**結果をコピー**してLINEに貼る
5. 店を出る前に「記録 → データ」でJSONを書き出す（バックアップ）

## データの保存場所

**この端末のブラウザ内だけ**に保存される。サーバーには何も送らない。

- 視察データ … localStorage
- 写真 … IndexedDB

機種変更・ブラウザのキャッシュ削除で消えるため、JSONの書き出しが唯一の保険。
書き出したJSONは「記録 → データ → JSONを読み込む」で復元できる。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Next.js 15（App Router）＋ React 19 ＋ Tailwind CSS v4。サーバー処理は無く、
全てブラウザ内で完結する。

### ファイル構成

| パス | 役割 |
| --- | --- |
| `lib/checklist.ts` | チェック項目75件のマスタ。項目の追加・修正はここだけ直す |
| `lib/types.ts` | 型定義 |
| `lib/score.ts` | 加重スコア・判定・前回比較・是正台帳の集計 |
| `lib/storage.ts` | **永続化はこの1ファイルに集約**。localStorage / IndexedDB を触るのはここだけ |
| `lib/store.tsx` | 画面から使う状態管理（storage.ts の上に乗る） |
| `lib/export.ts` | CSV／LINE用テキストの生成 |
| `app/` | 画面（ホーム／チェック／要改善／結果／記録） |

### Supabase などに差し替えるとき

UI からは localStorage / IndexedDB を一切触っていない。`lib/storage.ts` の
`Storage` インターフェース（`loadAll` / `saveAll` / `putPhoto` / `getPhoto` /
`deletePhoto` / `exportBundle` / `importBundle` / `clearAll` / `usageBytes`）を
別の実装に差し替え、末尾の `export const storage` をそちらに向ければ、
画面側の変更なしにクラウド共有へ移行できる。全て非同期で定義してある。

## デプロイ（Vercel）

1. [vercel.com/new](https://vercel.com/new) を開く
2. 「Import Git Repository」でこのリポジトリを選ぶ
3. Framework は Next.js が自動検出される。環境変数は不要
4. Deploy を押す

以降はこのブランチに push するたび自動でデプロイされる。
発行されたURLをスマホで開き、Safariの共有ボタン →「ホーム画面に追加」
（Androidはメニュー →「アプリをインストール」）で、アプリとして使える。
